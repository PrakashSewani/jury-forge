# Runbooks

One runbook per operational procedure, named `<slug>.md`. Each runbook contains: symptoms, impact,
diagnosis, mitigation, verification, and follow-up.

The required runbooks are listed in
[`../operations.md`](../operations.md#9-runbooks-to-write). None are written yet; they land with the
first operational implementation (Phase 1/4) and a restore drill.

A runbook is not done until someone has followed it end to end on a scratch environment.
